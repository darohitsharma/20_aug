# Python Basics, Worked Exercises

`Assignment_1_Solu.19aug (3).ipynb` contains introductory Python exercises with explanations: variable swapping, rectangle area, Celsius conversion and basic string operations (length, vowel counting, reversal, palindrome checks and space removal).

## Notebook structure

There are 26 cells: eight executable code cells and eighteen Markdown cells. Seven code cells request input. Examples use only built-in Python, without external packages, datasets or services.

## Run locally

Open with Jupyter or a notebook-capable editor using Python 3. Execute the examples in order and supply the requested numeric or text values. All eight code cells ran during documentation review with synthetic inputs; this is not exhaustive input validation or a performance benchmark.

The palindrome example removes ordinary spaces and lowercases its input before comparison. The final space-removal exercise removes ordinary spaces, not all whitespace. Numeric parsing and accepted dimensions are not broadly validated.
